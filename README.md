# Example1

This repository is a minimal example project intended to demonstrate a clean, review-friendly GitHub workflow.

## Purpose

- Provide a simple baseline for PR review exercises
- Keep the repository easy to understand and extend
- Serve as a starter repo for testing branch-based collaboration

## Current status

The repository is intentionally lightweight and ready for review. The branch `review/pr-readme` adds repository documentation so the project is easier to understand before any feature work begins.
